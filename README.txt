FORMA V6

Nouveautés :
- Espace client / profil détaillé
- Objectif, niveau, fréquence, durée, matériel, préférences et contraintes
- Mémoire Forma locale
- Coach IA conversationnel local
- Générateur de séances adapté au profil
- Plans Forma 4 / 8 / 12 semaines
- Adaptation selon le ressenti
- Créateur avec liste défilante et recherche d’exercices
- Catégories d’exercices
- Timeline de progression
- Progression physique optionnelle et locale
- Records, défis, streak, score et analyse
- Expérience 100 % silencieuse : aucune voix, aucune musique, aucun son
- Mise à jour automatique via Service Worker

Installation : déployer les fichiers à la racine de GitHub Pages puis ouvrir Forma sur iPhone.
