- annonces vocales via la synthèse vocale du téléphone
- enchaînement automatique des chronos et repos

- séries alternées gauche/droite
- notes et consignes par exercice
- favoris

- contrôle d'un son interne Forma

Limitation actuelle :
Le navigateur/PWA ne peut pas piloter directement Apple Music ou Spotify comme une application native. Le bouton musique contrôle seulement le son interne de Forma. L'intégration Apple Watch / fréquence cardiaque est volontairement préparée pour une future version native.

Après mise à jour sur GitHub Pages, si l'iPhone affiche l'ancienne version, supprimer l'icône Forma de l'écran d'accueil puis réouvrir le site Safari et réinstaller la PWA.
