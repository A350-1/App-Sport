FORMA V5 — Coach personnel PWA

Nouveautés :
- 3 modes : Je sais ce que je veux / Forma me coache / Surprends-moi
- générateur de séances local (sans API, prêt pour une future vraie IA)
- adaptation selon niveau, durée, matériel, muscles, contraintes et ressenti
- historique, records, volume, streak et Forma Score
- analyse « Pourquoi je progresse ? »
- défis personnels et progression élégante
- favoris
- échauffement automatique + compte à rebours 3 s
- alternance gauche/droite
- notes d'exercices
- supersets/circuits dans le créateur et les séances générées
- progression de poids prête à être enrichie dans une future version
- aucune voix, aucune musique, aucun son intégré : Forma est silencieuse
- migration automatique des données Forma V4 vers V5
- Service Worker versionné avec mise à jour automatique

IMPORTANT : cette V5 reste une PWA. Le générateur est volontairement local/déterministe afin de fonctionner sans clé API. Une vraie IA pourra être connectée plus tard via un backend sécurisé (ne jamais mettre une clé API secrète directement dans le HTML).
